## 已确认内容

- **A1 目标用户**：零基础入门者。
- **A2 学习目标**：能独立从零搭建同类项目。
- **B1 模板来源**：用户自己指定，AI 先评估是否适合当模板。
- **C1 推演依据**：主要参考 Git 历史；若相邻提交跨度过大，则按理想开发顺序重新构造。
- **C2 步骤粒度**：功能里程碑级，每步产出一个可运行的小功能（约 30~60 分钟）。
- **D1 语法安排**：用到什么学什么，每一步所需语法当场讲解。
- **D2 教学方法**：
  1. 学习者先用自然语言描述执行步骤；
  2. AI 不断追问，促使学习者修缮步骤；
  3. 学习者因缺乏编程思路答不上来时，AI 通过追问逼出需求，让学习者"创造"出一个概念；
  4. 执行步骤大致可行后，再引出对应的实际编程概念。
- **E1 验收标准**（同时满足）：
  - 能跑通：运行结果符合这一步的预期；
  - 与原项目对应代码对比，AI 点评差异；
  - 学习者能用自己的话说清楚这一步为什么这样做。
