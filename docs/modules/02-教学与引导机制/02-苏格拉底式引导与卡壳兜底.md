## 一、核心目标

在阶段推进对话的编码实践学习中，当学习者出现逻辑错误、思路盲区或卡壳时，通过引导与兜底机制避免 AI 沦为「直接代写工具」，确保学习者经历完整的「尝试 → 暴露问题 → 反思 → 修正」过程。

## 二、已有共识（来自已有规划）

- **不直接给答案**：出现问题时不直接给解决方案，只给方向（提问、举反例、提示可能缺少的知识背景）。
- **概念创造机制**：当用户因缺乏前置编程概念而想不出设计时，AI 用问题逼出需求，从而引出并创造该概念。
- **分阶段递进**：规划提出按「提示 → 类比 → 解答」分阶段推进，期间不时进行提问。
- **错误留痕**：本轮出错的地方需在「阶段 X 学习记录」中重点突出。
