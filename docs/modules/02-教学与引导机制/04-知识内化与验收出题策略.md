# 04 知识内化与验收出题策略

> **所属母模块**：`02-教学与引导机制`  
> **状态**：待讨论  
> **依据来源**：`docs/01-项目信息确认.md`（第四节、第六节）、`docs/项目规划记录.pdf`（Q1、Q3）、`docs/验证实践学习_Python学习Skill_项目规划.pdf`（三、四）

## 一、核心目标

确保学习者将规范项目的做法转化为内在知识与评判能力，而非机械复制；在阶段 C 验收中精准设计追问内容，检验学习者是否真正理解并具备跨场景迁移应用的能力。

## 二、已有共识（来自已有规划）

- **掌握的定义**：不只是懂，而是会用，能在不同背景、不同场所下用得好，并具备评判 AI 生成代码优劣的内在标准。
- **学习验收依据**：阶段 C 由总对话追问小块代码涉及的知识点，且需同时验证「项目重写」代码能跑通，两者都过才通过。
- **错题重点关联**：「阶段 X 学习记录」中需突出学习过程中出错的地方，为复习与追问提供重点依据。
- **终极验证标准**：学完后不看参考，能独立写出迁移项目的下一个需求。
