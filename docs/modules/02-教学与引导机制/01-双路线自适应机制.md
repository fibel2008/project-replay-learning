## 一、核心目标

通过「代码路线 / 自然语言路线」双轨机制自动适配不同编程起点的学习者，使零基础与有经验的学习者都能贯彻「先自己尝试，再揭晓原代码」的核心原则。

## 二、已有共识（来自已有规划）

- **自动适配定位**：不限用户编程起点，由用户自行判断当前小块能否用代码实现——能则走代码路线，不能则走自然语言路线。
- **代码路线流程**：用户编码实现 → 实现逻辑有误则提出问题、举反例追问并提示方向 → 循环直到逻辑正确 → **同样揭晓原代码，对比写法差异（命名、结构、惯用法）**。
- **自然语言路线流程**：用户用自然语言描述功能与行为步骤 → 实现逻辑无误（不要求与原项目完全一致）→ 引出源码逻辑（自然语言）并说出差异 → 引出编程基础知识 → 揭晓原项目代码，逐行讲解并与逻辑对应。
