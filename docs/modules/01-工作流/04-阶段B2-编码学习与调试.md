# 04 阶段B2-编码学习与调试

> **状态**：待讨论

## 一、核心目标

将本阶段架构拆解为小块代码，引导学习者按「先尝试 → 再揭晓原代码 → 写入项目重写并反复调试 → 提交 Git」的闭环完成本阶段编码实践，并同步沉淀项目记录与学习记录。

## 二、已有共识（来自已有规划）

- **执行角色**：阶段推进对话 X。
- **核心流程**：AI 拆成小部分小块代码 → 验收设计后开始编码 → 编码实践学习（代码路线 / 自然语言路线）→ 编码、调试完成。
- **项目重写节奏**：每学完一小块，就把这一块写进「项目重写」目录并反复调试。
- **代码路线揭晓**：逻辑正确后同样揭晓原代码，对比写法差异（命名、结构、惯用法）。
- **阶段收尾与产出**：用户提交 git 作为阶段结束的标志；AI 更新「阶段 X 项目记录」（进度、构思路径）与「阶段 X 学习记录」（知识点、突出出错处），之后回到总对话做验收。
