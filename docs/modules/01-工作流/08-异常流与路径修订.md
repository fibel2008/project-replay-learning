# 08 异常流与路径修订

> **所属母模块**：`01-工作流`  
> **状态**：待讨论  
> **依据来源**：`docs/01-项目信息确认.md`（第二节、第七节 #5）

## 一、核心目标

定义主干流程之外的非理想路径处理机制（如开发路径中途调整、验收未通过返工、学习中断恢复等），确保长期多阶段学习在出现偏差或变动时仍可控、可追溯。

## 二、已有共识（来自已有规划）

- **总纲可改性**：学习目标和项目范围不可更改；开发路径可由总对话修订，并留下修订记录。
- **迁移可跳过**：迁移练习（步骤 D/E）允许自由跳过且不记录。
