## 一、核心目标

作为每个阶段循环的入口，由总对话发布本阶段新增需求的 PRD X 并初始化阶段学习记录，让学习者清晰掌握本阶段目标后切入独立的阶段推进对话。

## 二、已有共识（来自已有规划）

- **执行角色**：总对话。
- **核心动作**：发布 PRD X，创建「阶段 X 学习记录」（空文件）。
- **本阶段产出**：PRD X、阶段 X 学习记录（空）。
- **对话切换**：用户手动开新对话（阶段推进对话 X），从仪表盘复制启动 prompt，靠工作台文件传递状态。
