## 一、核心目标

在动手写代码前，通过阶段推进对话引导学习者从 PRD X 出发理解原项目的架构设计与演进逻辑，并用自己的话复述沉淀为设计文档，培养对项目整体组织与架构的审美和判断力。

## 二、已有共识（来自已有规划）

- **执行角色**：阶段推进对话 X。
- **核心流程**：读取学习记录，拆解并分析 PRD X → 拆解原项目架构设计 → 讲解架构 → 用户创建设计文档。
- **设计文档方式**：AI 讲完架构后，用户用自己的话复述成设计文档；在项目文件夹中完成。
- **多周期架构演进**：因为需求不是一次给完，在后续阶段（第 2 个需求往后）会有多次调整、添补架构的时机，逐步过渡到让用户自行补充并与原项目找差距。
