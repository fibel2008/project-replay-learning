## 一、核心目标

规范学习过程中的代码版本管理边界与提交节点，以真实工程的 Git 习惯串联各阶段开发成果，并将用户 Git 提交作为阶段学习收尾的明确里程碑。

## 二、已有共识（来自已有规划）

- **Git 仓库范围**：「项目重写」「自行编码」**各自独立一个 Git 仓库**；**工作台不纳入 Git**。
- **阶段结束标志**：阶段 B 编码与调试完成后，用户提交 git 作为本阶段结束的标志，之后 AI 更新项目进度与学习记录，进入总对话验收。
