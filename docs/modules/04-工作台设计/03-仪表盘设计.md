## 一、核心目标

为用户提供只读可视化的学习进度总览，并降低手动多对话切换的操作成本，让用户能够一键复制对应阶段与模式的启动 prompt。

## 二、已有共识（来自已有规划）

- **功能定位**：可视化记录内容与项目进度，并提供便捷提示 prompt 的复制。
- **权限属性**：只读展示，读取工作台记录与状态文件并可视化。
- **初步形态（已搁置待细化）**：静态 HTML，数据来自 JSON 状态文件。
