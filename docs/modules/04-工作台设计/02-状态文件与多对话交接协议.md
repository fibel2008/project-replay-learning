# 02 状态文件与多对话交接协议

> **状态**：待讨论

## 一、核心目标

在用户手动开启多个独立对话（总对话 + 各阶段推进对话）的模式下，通过工作台中的结构化状态文件与 Markdown 记录完成跨对话状态传递，避免上下文丢失或进度错乱。

## 二、已有共识（来自已有规划）

- **多对话实现方式**：用户手动开新对话，从仪表盘复制启动 prompt；各对话靠工作台文件传递状态。
- **状态文件载体**：记录类文档用 Markdown；**另配一个小 JSON 状态文件记录当前阶段和步骤**。
- **核心载体**：工作台是存放总纲、记录、状态文件和仪表盘的目录，承担各对话间状态交接的职责。
