# 02 项目记录与学习记录

> **所属母模块**：`03-文档设计`  
> **状态**：待讨论  
> **依据来源**：`docs/01-项目信息确认.md`（第五节）、`docs/验证实践学习_Python学习Skill_项目规划.pdf`（三、四）

## 一、核心目标

规范每个阶段产出的两类核心过程文档——「阶段 X 项目记录」与「阶段 X 学习记录」，分别承载项目工程进度与个人知识沉淀，实现跨对话的状态延续与复盘追溯。

## 二、已有共识（来自已有规划）

- **记录格式**：记录类文档统一使用 Markdown。
- **阶段 X 项目记录**：
  - 存放位置：`工作台/项目记录/`。
  - 权责与内容：由阶段推进对话 X 创建并更新（本阶段内可更新），记录项目进度、构思开发路径。
- **阶段 X 学习记录**：
  - 存放位置：`工作台/学习记录/`。
  - 权责与内容：由总对话在步骤 A 创建（初始为空），由阶段推进对话 X 在本阶段内更新，记录本轮学到的知识点，**突出编码实践学习中出错的地方**。
