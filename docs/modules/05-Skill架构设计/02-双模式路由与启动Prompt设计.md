## 一、核心目标

设计清晰可靠的启动 Prompt 规范与模式路由规则，让同一个 Skill 在不同对话中准确进入「总对话」或「阶段推进对话 X」模式，且严格加载各自对应的参考文件与职责边界。

## 二、已有共识（来自已有规划）

- **路由机制**：由启动 prompt 指定当前对话模式（总对话 / 阶段推进对话），触发加载对应的内部参考文件。
- **触发方式**：用户手动开新对话后，从仪表盘复制启动 prompt 粘贴启动。
- **职责隔离**：总对话负责初始化、发布需求、验收、迁移练习；阶段推进对话负责单阶段的架构讲解与编码实践学习。
