# project-replay-learning

以一个真实、架构清晰的开源项目为模板，由 AI 逆向构造「MVP → 逐步迭代」的开发历程，引导学习者亲手「重放」项目开发并迁移到自己的项目中，通过实践真正掌握编程与架构能力。

---

## 一、当前状态

- **阶段**：模块拆解完成，进入分模块详细设计阶段
- **运行形态**：通用 Agent Skills（兼容 Claude Code / Cursor / Gemini CLI / Antigravity 等）
- **版本定位**：第一版先自用验证「实践 → 学习」方法（以 Python 为首个场景），跑通后再做成通用产品
- **设计文档**：详见 [`docs/modules/`](docs/modules/)（共 5 个母模块、21 个原子模块）

---

## 二、核心理念

1. **先自己做，再揭晓原代码**：学习者先尝试实现，AI 再揭晓原项目代码并对照讲解写法、命名与结构差异。
2. **只给方向，绝不代写**：卡壳时不直接给答案，通过提问、举反例与知识背景提示，保留「错误 → 反思 → 修正」的内化过程。
3. **双路线自适应**：不限编程起点——能写代码走「代码路线」，写不出来走「自然语言路线」（先理清逻辑，再对应源码与语法）。
4. **按真实开发周期演进**：只看原项目最终代码，由 AI 逆向拆解为 `MVP → 需求 2 → ...` 多轮开发周期，在反复迭代中培养整体架构审美。
5. **学一段，练一段**：每个阶段学完立刻在自己的迁移项目（结构相似、领域不同）中实践；终极标准是**不看参考能独立写出迁移项目的下一个需求**。

## 四、工作区结构

学习时由用户指定本地目录作为主文件夹，各对话靠「工作台」文件传递状态：

```text
学习主文件夹/
├── 原项目备份/          # 只读参照，用于对照讲解
├── 项目重写/            # [独立 Git 仓库] 按阶段重写原项目、存放用户设计文档
├── 自行编码/            # [独立 Git 仓库] 迁移练习：用户自己的项目（多阶段共用）
└── 工作台/              # 不纳入 Git，各对话间状态交接载体
    ├── 项目记录/        # 总纲（目标/范围不可改，路径可修订）+ 阶段 X 项目记录
    ├── 学习记录/        # 阶段 X 学习记录（知识点 + 重点标注出错处）
    ├── state.json       # 轻量状态文件，记录当前阶段与步骤
    └── 仪表盘           # 只读可视化进度，支持一键复制各对话启动 Prompt
```

---

## 五、工作流介绍

采用**手动多对话协作**：仅有一个「总对话」把控全局与验收，每个阶段开启一个独立的「阶段推进对话 X」专注教学，切换时从仪表盘复制启动 Prompt。

```text
[总对话] 0 初始化（仅一次）
    │
    ▼
┌──► A 发布需求（总对话）      ──► 发布 PRD X、创建空学习记录
│        │
│        ▼
│    B 阶段学习（阶段对话 X）   ──► B1 架构讲解与用户设计文档 → B2 编码学习与调试 → Git 提交
│        │
│        ▼
│    C 学习验收（总对话）      ──► 追问知识点 + 验证「项目重写」可跑通（双过才通过）
│        │
│        ▼
│    D 迁移练习（可选）        ──► 发布 PRD X'，在「自行编码」中实践（可跳过）
│        │
│        ▼
└─── E 迁移验收（总对话）      ──► 仅验功能实现 → 进入阶段 X+1
```

| 阶段 | 执行者 | 核心动作 | 关键产出 |
|---|---|---|---|
| **0 初始化** | 总对话 | 选模板项目、逆向规划路径、搭目录与依赖、选迁移题、生成总纲 | 总纲、工作区目录 |
| **A 发布需求** | 总对话 | 发布本阶段新增需求 PRD X，创建空学习记录 | PRD X、空学习记录 |
| **B 阶段学习** | 阶段对话 X | 讲架构 → 用户复述设计文档 → 拆小块双路线编码学习 → 重写调试 → Git 提交 | 设计文档、重写代码、阶段记录 |
| **C 学习验收** | 总对话 | 追问知识点 + 验证「项目重写」代码能跑通 | 阶段通过判定 |
| **D 迁移练习** | 总对话 + 用户 | 发布 PRD X'，在「自行编码」中模仿实现（可选，允许 AI 辅助、无指引） | 个人迁移项目代码 |
| **E 迁移验收** | 总对话 | 检查 X' 功能是否实现，通过后推进至下一阶段 `A(X+1)` | 状态流转 |
